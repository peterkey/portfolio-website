## Integration Findings

### Issues (2 — linked to requirements)

**1. FIX-02: CV download filename mismatch across two surfaces**

The CV is served correctly in both locations, but the filename the browser saves differs:

- `Navbar.tsx` line 139: `a.download = "Peter-Key-CV.pdf"`
- `HeroSection.tsx` line 342: `download="Peter_Williams-Key_CV.pdf"`

FIX-02 requires filename consistency. Phase 1 satisfied the requirement within Navbar scope; Phase 2 introduced a second download surface with a different filename without aligning with Phase 1.

**Fix:** Pick one filename and apply to both. Recommended: `Peter-Key-CV.pdf` (no spaces, no underscores mixed).

**2. DESIGN-03: useReducedMotion not applied to HeroSection or Navbar**

Phase 4 plan (04-03) applied `useReducedMotion` to 6 components. Two high-visibility, animation-heavy components were missed:

- **HeroSection.tsx**: 6 `motion.*` wrappers with `initial`/`animate`; perpetual scroll indicator bounce loop `animate={{ y: [0, 8, 0] }}` runs for all users regardless of OS setting.
- **Navbar.tsx**: `motion.nav` (hide-on-scroll), `motion.button` (whileHover/whileTap scale), `motion.div` (mobile menu) — none guarded.

These are the first components a user sees — the gap is most impactful here.

**Fix:** Add `useReducedMotion()` to both components and gate all `initial`/`animate`/`whileHover` props.

### No wiring issues

All 7 navbar anchors resolve to valid section IDs. Background alternation is correct across all 8 sections. Contact form → `/api/send` route → Resend is fully wired. CV files exist on disk.

### Informational (no requirement)

**Footer nav staleness:** `Footer.tsx` defines its own 5-entry navLinks (About, Skills, Experience, Projects, Contact) that predates Phase 3. Case Studies and Certifications are missing from footer navigation. All 5 existing links resolve to valid IDs — not broken, but inconsistent with Navbar.
